People

The only people who have a name, image, and bio presented is members of the executive committee.
They can change their details by Intranet > Exec Portal > Your Profile.
Anyone on the intranet can view this by Intranet > JCR Representatives. Anyone with "admin" rank can edit other profiles.
Only people with the "chair" rank, or "admin" rank (President, FACSO, Webmaster) can edit roles by Intranet > Exec's Portal > Position's Editor. Noting that should they remove themselves, then as soon as they submit the form, they will no longer have the same privileges.
The caveat is the President and FACSO's profile will automatically update to the main website front page.
Every change is logged. So, if you write something inappropriate, expect to be disciplined.

Student Groups

Student Groups exec can access their own group, by Intranet > Student Groups > (find their group) > Edit Society.
Any other exec member can do the same.
Any exec member can also update the roll of groups by Intranet > Groups Registry and then either create a new group, or find the group to edit.
Exec members can also delete the group.
Any changes will be visible to the intranet, as well as the main website. The main website however does not display names of exec members. or WhatsApp.
Every change is logged. So, if you write something inappropriate, expect to be disciplined.

The Public Website Pages

The public website has pages which only the webmasters can edit via GitHub, they are:

  • The front page - the exception is the president and FACSO bio, image, and name, which is synced from the profile pages of these people
  • Policies and Disclaimers - the exception is the policies, which can be uploaded directly by anyone with "admin" rank from the exec pages
  • Student Groups - the exception is the tiles which can be edited via the intranet by group execs, or any JCR exec member

You can edit the following pages:

  • Welfare
  • Freshers
  • The College
  • Contact
  • Events
  • Acknowledgements
  • Stash (though some caveats exist - noted below)

To do this, you must go Intranet > Exec's Portal > Pages, select which page.
From there, you can write the page content in Markdown. The top of the box has options including: view (view a preview of that section), double pages (left is what you write, right is what you should see), full screen, and then help - the help gives you guideance on how Markdown is set out.
Note that for images, you may chose to use HTML operators instead. You can see this in the college and events pages.
Markdown should be self-explanatory with the options you have, but there is a cheat sheet available here.
Images must be hosted by butlerjcr, so you must upload it and get a URL of the image to include. See above section.
After editing, if you're in full screen, come out of it, scroll down, select the declaration to be "I confirm my declaration for the above statement." - and then hit submit!
Every change is logged. So, if you write something inappropriate, expect to be disciplined.

Stash

Most of the steps for this is the same as "The Public Website Pages", however the stash pages are locked to the public. This is why the first two lines must read something like:
!open=May 21, 2026 17:00:00
!close=June 01, 2026 22:59:59
These dates are self explanatory. You must note the times are in UTC+0 - which means in summer time, 23:59:59 should be written as 22:59:59.
