People

The only people who have a name, image, and bio presented are members of the executive committee.

They can change their details by navigating to: Intranet > Exec Portal > Your Profile.

Anyone on the intranet can view this via Intranet > JCR Representatives. Additionally, anyone with "admin" rank can edit other profiles.

Only individuals with the "chair" rank, or "admin" rank (President, FACSO, Webmaster) can edit roles by going to: Intranet > Exec's Portal > Position's Editor. Please note that should they remove themselves, they will lose their privileges immediately upon submitting the form.

The caveat is that the President and FACSO's profiles will automatically sync and update directly to the main website front page.

Every change is logged. So, if you write something inappropriate, expect to be disciplined.

Student Groups

Student Groups exec can access their own group by going to: Intranet > Student Groups > (find their group) > Edit Society. Any other exec member can do the same.

Any exec member can also update the roll of groups via Intranet > Groups Registry and then either create a new group or find an existing group to edit. Exec members also have the authorization to delete a group.

Any changes made will be visible to both the intranet and the main public website. However, the main public website does not display the names of exec members or WhatsApp contact information.

Every change is logged. So, if you write something inappropriate, expect to be disciplined.

Uploading and Viewing Existing Images

If you are doing this for a student group or an exec member, please refer to the previous two sections.

However, if you need a general image uploaded, all you need to do is open up the page editor by going to: Intranet > Exec's Portal > Pages and selecting any page—ideally the one you want the image to appear on. From there, click the large "View and Upload Image" button.

Uploading should now be self-explanatory. Note that you are limited strictly to jpg, jpeg, and png files. You should rename files on your computer before uploading, and you may have to upload them one by one.

Every change is logged. So, if you upload something inappropriate, expect to be disciplined.

Below the upload tool, you will find the "Link Finder" section. Here, you can see all uploaded images, view them, or copy their direct URLs. You will need these links if you are editing a page, as you must reference the exact link to display the image.

Note that student group logos and exec officer avatars are explicitly excluded from this section. If you want to link to them instead, you can construct the URL manually using the following formats:

  • https://butler-jcr-public.s3.eu-west-2.amazonaws.com/societylogo/[societyId].jpg - for a student group (e.g., [societyId] could be spo-badminton, soc-butler-slacklining, or com-finance-committee)
  • https://butler-jcr-public.s3.eu-west-2.amazonaws.com/avatars/[cisCode].jpg - for an exec member, where [cisCode] is their personal CIS username

It is ideal to use these URL structures because if any updates are subsequently made to a student group logo or an avatar by the concerned member, the image changes across the site automatically!

The Public Website Pages

The public website has certain static pages which only the webmasters can edit directly via GitHub. These include:

  • The front page — with the exception of the President and FACSO bio, image, and name, which are automatically synced from their profile pages.
  • Policies and Disclaimers — with the exception of the policies themselves, which can be uploaded directly by anyone with "admin" rank from the exec pages.
  • Student Groups — with the exception of the directory tiles, which can be edited via the intranet by group execs or any JCR exec member.

On the other hand, you can directly edit the content of the following pages:

  • Welfare
  • Freshers
  • The College
  • Contact
  • Events
  • Acknowledgements
  • Stash (subject to some caveats noted below)

To do this, navigate to Intranet > Exec's Portal > Pages and select your target page.

From there, you can write the page content using Markdown syntax. The top of the editor pane features several helpful options, including: View (renders a quick preview of that section), Double Pages (splits the screen so the left displays your raw text and the right shows live rendering), Full Screen, and Help (provides a formatting guide on how Markdown is set out).

Note that for complex layouts or specific image sizes, you may choose to use raw HTML tags instead. You can find examples of this already in use on the existing College and Events pages.

Markdown layout rules should be self-explanatory with the provided toolbar options, but an external cheat sheet is also available here.

Remember that all images must be hosted by butlerjcr, meaning you must first upload the asset and retrieve its URL before placing it in your text (see the "Uploading Images" section above).

After you finish editing, exit full-screen mode if you are using it, scroll to the bottom of the page, check the confirmation declaration box ("I confirm my declaration for the above statement."), and hit submit!

Every change is logged. So, if you write something inappropriate, expect to be disciplined.

Stash

Most of the management steps for this section are identical to "The Public Website Pages".

However, the stash order pages are locked to the public outside of designated windows. Because of this restriction, the first two lines of your Markdown content box must explicitly define the availability window using this format:

!open=May 21, 2026 17:00:00
!close=June 01, 2026 22:59:59

These dates dictate exactly when the page goes live and when it locks down. You must carefully note that all times are evaluated in UTC+0. This means that during British Summer Time (BST), an intended local closing time of 23:59:59 must be written as 22:59:59.
