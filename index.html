Webmasters are listed here, so if you are stuck, you know who to contact within the university. Alternatively, if you are a new webmaster, and very stuck, you can contact me (Prem) by clicking on the hyperlink and going to my website - finding my LinkedIn / email.

Manual for JCR President / FACSO / Webmaster

If you want to edit the main website, you need GitHub, and be part of the organisation, and change the HTML of the pages in the public website repository. The files for these are in the `assets` folder. If you need to add pages on, and you don't know how to code beyond write HTML / edit it, please feel free to contact the webmaster (or previous webmasters, for new webmasters). The only thing that can be editted via the intranet is the president / FACSO bios, as displayed on the front website, and the societies / sports / committees, which also can be editted via the intranet. The intranet is pretty much dynamic. If you have skills in NodeJS, feel free to edit in the intranet repository, noting that `pageCommands` is the directory for the code that does anything for each page (POST, GET) - use examples from other pages if you want to add anything on. You can test locally by `npm install` and `node local.js`. It is set up to auto-deploy if you commit, and merge to the `main` branch.
