I don't have much technical knowledge - what do I need to do?

You: How much technical knowledge do I need to be webmaster?
Prem: You don't have to know how the backend works to be webmaster. I have designed the system, such that the majority of its maintenance can be done simply - just by being given permissions. A lot of stuff requires accurate data. In those cases, either it is you entering the correct CIS codes of exec members (Intranet >> Exec Portal >> Positions Editor), by making sure the data of the student groups are accurate (Intranet >> Exec Portal >> Groups Registry). Though - dump the responsibility of these on the JCR Vice President (who deals with committees), the JCR Sports Officer, and the JCR Society Officer (what they oversee is obvious).

You: Wait, so do I ever need to touch any code, or do any wizardry?
Prem: Well.... the good news is a lot of things can be managed through the intranet portal - heck, the exec members themselves get to edit their profiles, and group leaders get to do so for their grouo - and the image, bio, and name the president and FACSO put for themselves will be reflected to the full website automatically, there will still be some aspects. The following questions will solve them.

You: So, what do I need to change in terms of code?
Prem: Well, unless a better way has been done, you may need to edit the welfare pages (https://www.butlerjcr.com/welfare) and the freshers page (https://www.butlerjcr.com/freshers) manually. If you know HTML that is great, because what you need to do is go to the GitHub repository (https://github.com/josephinebutlerjcr/public-website), navigate to "assets", then "html", and then find the relevant page, e.g. "welfare.html", and press "edit this file". You can then manipulate the HTML. This should be straight forward if you are changing a few words. Unless you are certain for what you are doing, do not touch anything outside of this folder, however.

Also, after you have done editting, press the green "Commit changes" button - if you are confident all the words you put in are correct / not mispelt. Then, you will get the option to write a commit message (just a brief title, e.g. "changed for freshers 2026"), and then select "Commit directly to the main branch" and "Bypass rules and commit changes". If you do not get this option, refer to the next question.

You: Wait, what is GitHub?
Prem: Ah - sorry - forgot to mention. It is basically like Google Drive / DropBox / cloud storage but for code. You will need a GitHub account, which you should be able to make easily, and you will need to get the previous webmaster to add you onto the organisation.
You may however experience problems when making edits. If you can not "commit directly to the main branch" you can keep the other option of "create a new branch for this commit" and then press the commit button, and then get the previous webmaster to accept the pull request, and indeed, to let you make changes.

Why The Design Choice?

You: There was a previous website - why did you change it fully?
Prem: The former website was good, a lot of which inspired what is going on here (thanks Ned!) - however when the former webmaster, Ned, graduated, he still had to do a lot of work to change things. Then, I came in. But, given I was a fresher (at the time), I decided, you know what, let's address some inefficiencies. For one, I changed the entire structure, from it running on a server, to a serverless architecture - because paying for a constant server was expensive. For the 2 of you who actually use the JCR website, that means the server is mostly dormant. Hence, serverless. It saves us so much money!

You: But, what about storing photos?
Prem: Yes, I did have the debate with Ned (the previous webmaster), and that was, at the time, the weakness to my structure - S3 costs tend to be higher.
However - I decided to still go ahead with my idea, since no one even uploaded photos to the website.
Since then, in my capacity as CGO (but also webmaster), I got us the free Google Workspace as a charity. This includes a LOT of storage for photos, on Google Photos. The UI for Google Photos is amazing. We can now hoard our photos there!
